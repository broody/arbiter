# referee docs

The developer guide, built with [Vocs](https://vocs.dev).

```bash
npm install
npm run dev      # http://localhost:5173 (node scripts/dev.mjs; see its header)
npm run build    # fails on dead links
npm run preview
```

Pages are MDX in `src/pages`; the sidebar is in `vocs.config.ts`. See
[STYLE.md](STYLE.md) before writing.
